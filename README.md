#  Password Generator

A simple password generator built with HTML, CSS and JavaScript.

## Features

- Generate random passwords
- Adjustable password length
- Uppercase and lowercase letters
- Numbers and symbols
- Password strength indicator
- Copy password to clipboard

## Technologies Used

- HTML
- CSS
- JavaScript
